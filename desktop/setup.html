Cellovision

Watch from a Cellovision server

On the same Wi-Fi as the server? Find it, or type its address (like 192.168.1.20).

Make this computer the server

Your movies, shows, music and photos are on this computer? Run the server here: every phone, TV and computer at home can watch from it. It starts when you sign in and keeps running in the tray.

The first time, Cellovision downloads FFmpeg (about 100 MB, open source) to convert videos for devices that can't play them. If Windows asks whether to let Cellovision use the network, choose Allow (private networks).
